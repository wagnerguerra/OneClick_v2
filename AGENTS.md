# Instruções para agentes de IA

Este repositório usa o **`CLAUDE.md`** (na raiz) como fonte única de instruções
para qualquer ferramenta de IA — Claude Code, Cursor, Codex, Copilot, Gemini ou
outra. Leia-o inteiro antes de escrever código; as regras valem igualmente para
todas as ferramentas.

Antes de criar ou tocar uma tela, leia também:

- `docs/PADRAO_CORES_E_TEMA.md` — cor primária, cores com significado, campos,
  gráficos e a cor de módulo (que **não** entra no conteúdo das telas);
- `docs/PADRAO_PAGINAS.md` — como se monta listagem, kanban e detalhe;
- `/admin/design-system` (no sistema, master) — referência viva dos padrões
  visuais, com exemplos; em caso de dúvida, ela vence.

Não copie regras para este arquivo: ele só aponta. Atualize o `CLAUDE.md` e os
docs acima.
